# 🚀 Jetpack Compose Wrapper

**Compose Wrapper** is an open-source IntelliJ IDEA and Android Studio plugin designed to boost your productivity when building UIs with Jetpack Compose. 

Tired of manually cutting and pasting code just to wrap a `Text` in a `Column`? This plugin does it for you in two clicks!

![prev](https://github.com/user-attachments/assets/69252140-feb4-4186-ac80-4754b3e5c657)

---

## ✨ Features

- ⚡ **Instant Wrapping**: Wrap any Composable with `Row`, `Column`, `Box`, `LazyRow`, or `LazyColumn`.
- 📦 **Smart Item Placement**: Automatically adds `item { ... }` blocks when wrapping with Lazy layouts.
- 🛠️ **Auto-Import**: Automatically adds missing Compose foundation imports to your file.
- 🧹 **Auto-Format**: Reformatting the wrapped code immediately for a clean look.
- ⌨️ **Native Integration**: Works seamlessly with the standard `Alt + Enter` intention menu.

---

## 📸 How It Works

1. Place your cursor on a Composable function (e.g., `Text`, `Button`).
2. Press `Alt + Enter`.
3. Select **"Wrap with Row/Column/Box/Lazy..."**.
4. Choose your wrapper from the popup menu.

---

## 🛠️ Installation

### From Marketplace
- Open Android Studio -> Settings -> Plugins -> Marketplace.
- Search for "Compose Wrapper" and click Install.

### Manual Installation
1. Download the latest release `.zip` file from the [Releases](https://github.com/mehrdadmmb2/Jetpack-Compose-wrapper/releases) page.
2. Open Android Studio -> Settings -> Plugins.
3. Click the ⚙️ icon and select **"Install Plugin from Disk..."**.
4. Select the downloaded `.zip` file.
